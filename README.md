# Password Generator 🔐

A simple, interactive, and responsive password generator built using HTML, CSS, and JavaScript. Generate random passwords with customizable length and character options, along with a password strength indicator.

## 🌟 Features
- Generate random passwords up to 50 characters
- Customizable password length
- Copy password to clipboard
- Password strength indicator (Weak, Fair, Good, Strong)
- Visual strength meter
- Copy confirmation notification
- Fully responsive design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 📂 Project Files
- `index.html` — The main structure of the webpage
- `style.css` — The styles and responsive design
- `script.js` — Password generation, clipboard functionality, and strength calculation

## 💻 How to View Locally
1. Download or clone this repository to your computer.
2. Open the project folder.
3. Run `index.html` using VS Code Live Server.
